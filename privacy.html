Lantern Media

Privacy Policy

Last updated: November 2, 2026.

Who this policy covers

This policy describes the data practices of Lantern Media (10X Lead Pro LLC), the operator of a small set of YouTube channels and companion products (together, "Lantern"). Lantern is a single-operator production: every YouTube channel, Google Cloud project and Google account it touches is owned by the operator. Lantern's software does not authenticate on behalf of, or access data belonging to, anyone other than its own operator.

What data Lantern's software accesses

SourceWhat is accessedWhy
YouTube Data API v3, via OAuth on the operator's own Google accounts The operator's own channel and video metadata (titles, descriptions, tags, privacy status, upload status); the ability to upload new videos to the operator's own channels Publishing and managing Lantern's own content
YouTube Analytics API, via the same OAuth grant Performance metrics for the operator's own channels and videos (views, average view duration, audience retention, and revenue-adjacent metrics where available) Measuring how the operator's own content performs, to decide what to make next

Lantern's software never requests access to any other person's YouTube account, channel, or videos, and never collects data about people who merely watch or comment on its videos beyond what YouTube's own public Analytics aggregates provide to every channel owner. There are no end-user accounts, no sign-up forms, and no third-party user data processed by this application.

What Lantern's software does not do

  • It does not sell, rent, or share any accessed data with any third party.
  • It does not use YouTube API data to build user profiles for advertising.
  • It does not access data from any Google account other than the operator's own (listed in Lantern's internal access records, not published here).

Local Spotlight consent (a different, separate data flow)

Lantern also runs a small local-business feature ("Local Spotlight") that records information about local businesses the operator may feature, and any media/consent those businesses explicitly grant for that purpose. See the consent form page for what is collected there and how a business can withdraw consent. This is unrelated to the YouTube API data described above.

Retention

YouTube/Analytics data read through the API is retained only as long as needed to operate and report on Lantern's own channels, and is stored in Lantern's private database, not published or exported except in aggregate form (e.g., view counts shown on Lantern's own internal dashboard). OAuth tokens are stored in the operator's local credential store, never in source control, and can be revoked at any time from the Google Account's own security settings, which immediately stops all further access.

Children's privacy

Lantern does not knowingly collect personal information from children. Where a Lantern channel's content is made for kids, videos are flagged accordingly to YouTube (selfDeclaredMadeForKids) and no comments, personalized ads, or data collection beyond standard YouTube platform mechanics are enabled for that content.

Changes to this policy

If Lantern's data practices change, this page will be updated and the "last updated" date above will change accordingly.
